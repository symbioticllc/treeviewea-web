Section 01 · Architecture & Deployment

Quickstart, Installation & Runtime Modes

TreeviewEA v2.5.0 ships as a zero-dependency signed macOS application bundle (TreeviewEA.app) powered by an embedded Go HTTP/HTTPS server, a native Cocoa WKWebView window, a Rust Compressed Sparse Row (CSR) graph engine, and a Python ONNX/Ollama/Redis drift worker.

 1.1 macOS Native Application Bundle & WebKit Shell

When launched from /Applications/TreeviewEA.app (distributed via TreeviewEA-2.5.0-macOS-arm64.dmg), the binary links directly against macOS AppKit.framework, WebKit.framework, and PDFKit.framework (internal/macos/webview_darwin.go & window_darwin.go):

🪟 Native Cocoa WKWebView Window

Hardware-accelerated WKWebView shell with native macOS menu bar integration (⌘Z Undo, ⇧⌘Z Redo, ⌘X/C/V/A/D, ⌘P Print), native file dialogs (NSOpenPanel / NSSavePanel), and Finder reveal (NSWorkspace).

webview_darwin.go WKWebView NSPrintOperation

⚡ Embedded Go + SQLite + TLS Engine

Binds to an automatic loopback port (or a user-specified -port) for REST API calls and simultaneously launches a dedicated HTTPS/TLS 1.3 MCP listener on https://localhost:8443/api/mcp with auto-trusted local Root CA certificates.

server.go mcp_tls.go https://localhost:8443

🗂️ Workspace Auto-Discovery & Seeding

On first launch, TreeviewEA seeds ~/TreeviewEA/ from TreeviewEA.app/Contents/Resources/Templates/, preferring Blank-Project.tvwx as the clean startup repository and discovering all .tvwx, .qea, and .eapx files.

~/TreeviewEA Blank-Project.tvwx Info.plist
macOS Installation & CLI Execution 
# 1. Mount the signed macOS Disk Image (.DMG) and copy TreeviewEA.app to /Applications
$ hdiutil attach TreeviewEA-2.5.0-macOS-arm64.dmg
$ cp -R /Volumes/TreeviewEA/TreeviewEA.app /Applications/
$ open -a /Applications/TreeviewEA.app

# 2. Launch with a specific .tvwx or legacy .qea repository file
$ /Applications/TreeviewEA.app/Contents/MacOS/treeview-ea -file ~/TreeviewEA/TransactionPlatform-Architecture.tvwx

# 3. Run in headless HTTP + HTTPS MCP server mode (CI/CD, browser access, or remote agent workflows)
$ /Applications/TreeviewEA.app/Contents/MacOS/treeview-ea -server -port 8080 -mcp-tls-port 8443 -file ./Enterprise.tvwx

# 4. Initialize a pristine, empty Blank-Project.tvwx from the command line
$ /Applications/TreeviewEA.app/Contents/MacOS/treeview-ea -init-blank ./Clean-Architecture.tvwx

Every INSERT, UPDATE, and DELETE records exact row-level inverse SQL statements with interaction group coalescing (`X-Undo-Group`), enabling sub-millisecond ⌘Z / ⇧⌘Z rollback with zero primary-key drift.
