Section 01 · Getting Started in 3 Minutes

Installing TreeviewEA & Creating Your First Project

TreeviewEA is a self-contained macOS application. You do not need to install any external database server, Java runtime, or browser extension to start modeling—everything works out of the box from the moment you drag TreeviewEA.app into your Applications folder.

 1.1 Step-by-Step First-Time Installation

1️⃣ Step 1: Download & Drag to Applications

Download TreeviewEA-0.7.0-macOS-arm64.dmg, double-click to open the disk image, and drag TreeviewEA.app into your macOS /Applications folder. Launch TreeviewEA from Spotlight, Launchpad, or Finder.

Apple Silicon (arm64) Zero Dependencies

2️⃣ Step 2: Create or Open a Project (⌘N / ⌘O)

On first launch, TreeviewEA creates a dedicated ~/TreeviewEA/ workspace folder in your home directory. Click 🗂️ Project ▾ → New Project (⌘N) to start with a clean Blank Project or choose a 1-Click Industry Framework Template that pre-builds folders, starter elements, and a master diagram for you.

~/TreeviewEA/ Blank or Template .tvwx File

3️⃣ Step 3: Model Visually or Use the AI Co-Pilot

Drag elements from the Left Toolbox onto the canvas, Double-Click any shape (or press F2) to rename it, draw connectors between layers, or open the 🤖 AI Architecture Advisor (and optional Claude Desktop / Cursor integration) to scaffold and review models automatically.

Left Toolbox Double-Click Rename ⌘Z Undo / Redo

✏️ 2.3 Everyday Canvas Workflows (Rename, Nest, Connect & Rotate)

✏️ Double-Click (or F2) In-Line Shape Rename

To rename any element on the canvas, simply Double-Click its shape (or select it and press F2). Type the new name right on the diagram and press Enter to save (or Esc to cancel). The new name automatically updates in the Model Explorer, Object Catalog, and every other diagram where that element appears.

Double-Click / F2 Enter to Save

📦 Drag-and-Drop Package Nesting («contains»)

To group capabilities, microservices, or cloud resources inside a parent Package or Boundary container, simply drag the element inside the container box on the canvas. TreeviewEA automatically nests the element inside the parent folder, creates a formal «contains» relationship, and moves children together when you drag the parent. Drag it back out anytime to detach.

Auto Parent Nesting «contains»

🎯 Drawing Connectors: Edge Snap vs. Body Auto-Snap

Select the Connector tool (L or C) or drag from a shape's connection handle:
• Edge-Point Snap: Drop the line on a specific point along a shape's border to lock that exact anchor point.
• Body Auto-Snap: Drop the line anywhere inside the shape body to let TreeviewEA automatically route along the nearest edge. Drag orange bend handles (■) or click blue + midpoints to add custom corners.

Edge-Point Snap Body Auto-Snap Bend Waypoints

🔄 360° Shape Rotation & 1-Click Auto-Layout

Rotate any selected shape around its center by dragging its top ↻ handle (snaps every 15°, or hold Shift for 1° precision), or press R (+90°), ⇧R (-90°), or 0 (reset). Need to tidy up a complex diagram? Click 📐 Auto-Layout in the toolbar to arrange elements into a clean hierarchy, flow, radial ring, or grid.

360° Rotate (R / ⇧R) 8 Auto-Layout Modes

🏛️ 4.1 When & How to Use Each of the 8 Optional Frameworks

Not sure which framework fits your initiative? Use this practical comparison to pick the right methodology—or mix and match them across your repository:

🎯 1. Gartner Enterprise Architecture Method (GARTNER)

Best for: CIO/CTO roadmaps, application portfolio rationalization, and linking executive business outcomes to investment decisions.
• Layer 1 — Future-State Business Outcomes: «BusinessOutcome» & «SignatureReadyPlan».
• Layer 2 — PACE-Layered Application Strategy: Classify systems by rate of change and competitive advantage: «SystemOfInnovation» (fast experimentation), «SystemOfDifferentiation» (unique IP), «SystemOfRecord» (core ledger/ERP), and «PackagedBusinessCapability» (composable API building blocks).
• Layer 3 — TIME Portfolio Valuation: Score assets as «InvestAsset», «TolerateAsset», «MigrateAsset», or «EliminateAsset».
• Layer 4 — Gap Analysis & 1…M Transition Waves: «TargetStateGap» & «TransitionWave».

Framework: GARTNER Toolbox: gartner Wizard: gartner-pace-time

🏛️ 2. BizBOK® v14 Business Architecture Guild (BIZBOK)

Best for: Business architects building L1–L3 capability maps, end-to-end customer value streams, and business-to-IT cross-mappings.
• Layer 1 — Core Quartet Blueprints: «Capability», «ValueStream», «ValueStreamStage», «InformationConcept», and «BusinessUnit».
• Layer 2 — Extended Governance Domains: «StrategicObjective», «BusinessPolicy», «Stakeholder», «ProductMapping», and «Initiative».
• Layer 3 — Cross-Mapping Blueprints: Connect value stages to enabling capabilities and IT systems using «ValueStageCapabilityMap», «CapabilityToSystemLink», and «InformationToEntityLink».

Framework: BIZBOK Toolbox: bizbok Wizard: bizbok-guild

🛡️ 3. SABSA® 6×6 Enterprise Security Architecture (SABSA)

Best for: Security architects designing zero-trust architectures where every technical control traces back to a business risk attribute across all 6 Sherwood rows (R1..R6):
• L1 Contextual (R1): «BusinessRiskAttribute», «ThreatDomain»
• L2 Conceptual (R2): «SecurityControlObjective», «TrustBoundary»
• L3 Logical (R3): «LogicalSecurityService», «SecurityPolicy», «ProtectedInformationAsset»
• L4 Physical (R4): «PhysicalSecurityMechanism», «SecurityDataSchema»
• L5 Component (R5): «SecurityComponent»
• L6 Operational (R6): «OperationalSecurityNode», «SecurityIncidentPlaybook», «AssuranceAuditTrail»

Framework: SABSA Toolbox: sabsa Wizard: sabsa-security

🔐 4. NIST CSF 2.0 & SP 800-53 Rev. 5 (NIST)

Best for: Cybersecurity compliance, audit readiness, and mapping NIST controls directly onto applications, databases, and cloud infrastructure:
• All 6 NIST CSF 2.0 Core Functions: «NIST_Govern» (GV), «NIST_Identify» (ID), «NIST_Protect» (PR), «NIST_Detect» (DE), «NIST_Respond» (RS), and «NIST_Recover» (RC).
• NIST SP 800-53 Rev. 5 Control Families: «ZeroTrustAccessControl» (AC/IA), «CryptographicProtection» (SC-8/SC-28), «AuditAndAccountability» (AU/SI), and «ContingencyPlanControl» (CP/IR).

Framework: NIST Toolbox: nist Wizard: nist-csf-80053

🏛️ 5. TOGAF® Standard, 10th Edition (TOGAF10)

Best for: Structured enterprise transformation following the Architecture Development Method (ADM).
