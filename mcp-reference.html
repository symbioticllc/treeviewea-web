4.2 Graph Algorithms & Mathematical Specifications

🔄 1. Tarjan’s Strongly Connected Components (SCC)

Executes single-pass depth-first search (detect_cycles_tarjan()) maintaining discovery indices[u] and lowlink[u] invariants on an explicit call stack to detect all multi-node circular dependency loops in $O(|V| + |E|)$ linear time.

lowlink[u] = min(lowlink[u], lowlink[v]) (tree edge u → v)
lowlink[u] = min(lowlink[u], indices[v]) (back edge to stacked v)
Root SCC iff lowlink[u] == indices[u] && |SCC| > 1

🎯 2. Brandes Shortest-Path Betweenness Centrality

Identifies architectural bottlenecks and Single Points of Failure (compute_betweenness()) by running unweighted BFS shortest-path counting $\sigma_{st}(v)$ followed by reverse stack dependency accumulation $\delta_{s\bullet}(v)$ normalized across all node pairs.

δ_{s•}(v) = Σ_{w : v ∈ P_s(w)} (σ_{sv} / σ_{sw}) · (1 + δ_{s•}(w))
C_B(v) = [ Σ_{s ≠ v ≠ t} (σ_{st}(v) / σ_{st}) ] / ((|V| - 1)(|V| - 2))

📈 3. Degree-Normalized Power-Iteration PageRank

Quantifies structural authority (compute_pagerank(0.85, 25)) across 25 power iterations over the CSR adjacency slice with damping factor $d = 0.85$ and full dangling-node mass conservation ($O(25 \cdot |E|)$).

PR^{(t+1)}(v) = (1 - d)/|V| + d · (Dangling^{(t)} / |V|)
+ d · Σ_{u ∈ N_in(v)} [ PR^{(t)}(u) / |N_out(u)| ]

🧬 4. 6-Stratum Lineage, Blast Radius & Readiness

Verifies 5-hop conceptual lineage to $L_0/L_1$ (has_conceptual_lineage()), 3-hop undirected Blast Radius percentage (compute_blast_radius(3)), 2-hop 6-interrogative coverage (C1..C6), and Dynamic Capability Readiness:

Readiness(k) = clamp_{[18,100]}( 0.38·Ψ_vert + 0.37·Ψ_horiz + 0.25·Ψ_affin - Δ_drift )
Coherence = clamp_{[15,100]}( 0.45·Vert% + 0.35·Horiz% + min(25, 1.2·N_cells) - 0.18·Drift )
